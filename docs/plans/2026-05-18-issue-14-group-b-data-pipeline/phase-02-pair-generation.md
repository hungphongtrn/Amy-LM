# Phase 2: DeepSeek Pair Generation

> **Status:** STUB — will be detailed after Phase 1 completes.

## Phase Goal
All ~4K enriched NVTTS samples have chosen/rejected response pairs generated by DeepSeek V4 Flash, checkpointed to JSONL.

## Files to Touch (Tentative)
- `scripts/generate_preference_pairs.py`
- `tests/data/test_generate_pairs.py`

## High-Level Scope
- Load enriched dataset from `data/nvtts_enriched/`
- Async batched DeepSeek V4 Flash API calls with JSON structured output
- Two prompts per sample: good (rich context) and bad (stripped context)
- Checkpointed JSONL output: `data/nvtts_pairs/pairs.jsonl`
- Retry with exponential backoff (max 3), skip with error log after max retries
- DEEPSEEK_API_KEY from environment
- Configurable concurrency (default: 10)
